# AI Orbit Directory 🪐

[![Deploy with Vercel](https://vercel.com/button)](https://ai-orbit-directory.vercel.app)

A modern web directory to discover, explore, and search vetted AI applications and tools. Built with Next.js 15, Tailwind CSS, and Neon PostgreSQL.

🚀 **Live Demo:** [https://ai-orbit-directory.vercel.app](https://ai-orbit-directory.vercel.app)

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Database:** Neon Serverless PostgreSQL
- **Hosting:** Vercel
